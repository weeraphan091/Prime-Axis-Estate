► วิธีที่ 1 (ง่ายสุด) — ดับเบิลคลิก

  1. ติดตั้ง Node.js ก่อน (ครั้งเดียวเท่านั้น)
     - เปิด Chrome/Edge ไปที่: https://nodejs.org
     - กดปุ่มสีเขียว "Download Node.js (LTS)"
     - เปิดไฟล์ที่โหลดมา แล้วกด Next เรื่อยๆ จนติดตั้งเสร็จ
     - ปิดเครื่องหรือรีสตาร์ทคอม (แล้วแต่จะเลือก)

  2. ดับเบิลคลิกไฟล์ "start.bat" ในโฟลเดอร์นี้

  3. รอจนหน้าต่างดำขึ้นคำว่า "Ready" หรือ "compiled"

  4. เปิดเบราว์เซอร์ (Chrome/Edge) พิมพ์ในแถบที่อยู่:
     http://localhost:3000
     แล้วกด Enter

  จะเห็นหน้าเว็บแล้ว


► วิธีที่ 2 — ใช้ Terminal ใน Cursor

  1. ติดตั้ง Node.js ตามข้อ 1 ด้านบน (ถ้ายังไม่ได้ติดตั้ง)

  2. ใน Cursor กด Ctrl+` เพื่อเปิด Terminal (หรือเมนู View > Terminal)

  3. พิมพ์ทีละคำสั่งตามนี้ แล้วกด Enter ทีละอัน:

     cd "c:\Users\Zhong\OneDrive\เดสก์ท็อป\อสังหา"

     npm install

     npm run dev

  4. รอจนขึ้น "Ready" แล้วเปิดเบราว์เซอร์ไปที่ http://localhost:3000


► ปิดเว็บเซิร์ฟเวอร์
  - ถ้าใช้ start.bat: ปิดหน้าต่างดำ หรือกด Ctrl+C แล้วกด Y
  - ถ้าใช้ Terminal: กด Ctrl+C ใน Terminal


► ถ้าเปิดไม่ได้
  - ให้แน่ใจว่าติดตั้ง Node.js แล้ว และรีสตาร์ทคอมแล้ว
  - ลองดับเบิลคลิก start.bat อีกครั้ง
  - หรือเปิด Command Prompt (กด Win+R พิมพ์ cmd กด Enter)
    แล้วไปที่โฟลเดอร์โปรเจกต์ แล้วพิมพ์: npm install แล้ว npm run dev
