# พัทยา พร็อพเพอร์ตี้ — เว็บไซต์อสังหาริมทรัพย์พัทยา

เว็บไซต์ปล่อยเช่า/ขายอสังหาริมทรัพย์ในพัทยา แบบมืออาชีพ รองรับการฝากขาย-ฝากเช่าโดยเจ้าของทรัพย์โดยตรง

## ฟีเจอร์หลัก

- **หน้าแรก** — Hero, ค้นหาด่วน, รายการแนะนำ, CTA ฝากขาย/เช่า
- **ค้นหาทรัพย์** — กรองตาม ประเภท (ขาย/เช่า), ประเภทอสังหา, พื้นที่, ช่วงราคา
- **หน้ารายละเอียด** — ข้อมูลเต็ม, รูป, จุดเด่น, ปุ่มโทร/อีเมลติดต่อ
- **ฝากขาย/ฝากเช่า** — ฟอร์มให้เจ้าของลงประกาศได้เอง (ชื่อ, ประเภท, ราคา, ที่ตั้ง, ขนาด, จุดเด่น, ข้อมูลติดต่อ)
- **ติดต่อเรา** — ข้อมูลติดต่อ + ฟอร์มส่งข้อความ
- **UX/UI** — สะอาดตา, รองรับมือถือ, ฟอนต์ DM Sans / DM Serif Display

## วิธีรัน

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ที่ [http://localhost:3000](http://localhost:3000)

## ฐานข้อมูล (DB) และหลังบ้าน

โปรเจกต์ใช้ **SQLite** ผ่าน **Prisma** — เก็บเป็นไฟล์ `prisma/dev.db` ไม่ต้องติดตั้ง MySQL/PostgreSQL

### ครั้งแรก (สร้างตาราง + ใส่ข้อมูลตัวอย่าง)

```bash
npx prisma generate
npx prisma db push
npm run db:seed
```

- `db push` — สร้าง/อัปเดตตารางจาก `prisma/schema.prisma`
- `db:seed` — ใส่รายการตัวอย่าง 6 รายการ

### หลังบ้าน (Admin)

- **URL:** [http://localhost:3000/admin](http://localhost:3000/admin)
- **ล็อกอิน:** ไปที่ `/admin/login` ใส่รหัสผ่านแอดมิน
- **รหัสผ่าน:** ตั้งใน `.env` เป็น `ADMIN_PASSWORD=...` (ถ้าไม่มีจะใช้ `admin123`)

หลังล็อกอินสามารถ:

- **จัดการรายการ** — ดู แก้ไข ลบ รายการทั้งหมด
- **ลงลิสใหม่** — เพิ่มรายการขาย/เช่า (หัวข้อ, ประเภท, ราคา, ที่ตั้ง, รูป URL, จุดเด่น, ติดต่อ ฯลฯ)

รายการที่ลงจากหลังบ้านจะโผล่ในหน้าค้นหาทรัพย์และหน้าแรกทันที (ดึงจาก DB ผ่าน API)

## โครงสร้าง

- `src/app/` — หน้า (App Router)
- `src/components/` — Header, Footer, SearchBar, PropertyCard, ListingsResults
- `src/data/properties.ts` — ข้อมูลตัวอย่าง (แทนที่ด้วย API/DB ได้)
- `src/types/property.ts` — TypeScript types
